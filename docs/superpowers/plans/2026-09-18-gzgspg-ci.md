# gzgspg CI 构建与发布实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 gzgspg 加一套 GitHub Actions CI，产出 Windows（386/amd64/arm64）的纯 exe 与 system/user 双 MSI、Linux（386/amd64/arm64）的裸二进制与 deb/rpm/AppImage、macOS（amd64/arm64）的 `.app` 与 `.dmg`，并在打 tag 时创建 draft release。

**Architecture:** 三段式 workflow（`check` → `build` 矩阵 → `release`）。与 `gzgspd` 的 CI 最大差异是 **Fyne 必须 `CGO_ENABLED=1`**，因此每个平台跑在对应原生 runner 上，不做纯交叉编译。打包用 nfpm（deb/rpm）、WiX v4（MSI）、linuxdeploy + appimagetool（AppImage）、sips/iconutil/hdiutil（macOS）。

**Tech Stack:** Go 1.27、Fyne v2.8.1、GitHub Actions、WiX v4、nfpm、linuxdeploy、appimagetool、hdiutil。

## Global Constraints

- Go 版本：`go.mod` 为 `go 1.27.0`；workflow 用 `go-version: "1.27"`。若 runner 上 `actions/setup-go` 尚无法提供 1.27，改用可用的最新稳定版并在 spec 的「风险 4」处记录。
- `CGO_ENABLED=1` 全平台。**不得**照搬 gzgspd 的 `CGO_ENABLED=0`。
- `GOTOOLCHAIN=local`，避免构建期临时下载工具链。
- 构建参数统一：`-trimpath -ldflags "-X 'github.com/summonhim/gzgspg/internal/version.Value=${VERSION}' -X 'github.com/summonhim/gzgspg/internal/version.BuildTime=${BUILDTIME}' -w -s"`。
- 版本号：tag `v1.3.0` → 包版本 `1.3.0`，MSI 内部四段 `1.3.0.0`；非 tag → `0.0.0-<GITHUB_RUN_NUMBER>`，仅构建验证。
- 文件名格式：`gzgspg-<goos>-<arch>-<ver>[.<ext>]`；Windows 额外 `-system` / `-user` 后缀。
- 应用 ID：`top.summonhim.gzgspg`；应用名：`gzgspg`；显示名：`广工商校园网登录器`。
- 触发：push main（忽略 `README.md`、`.gitignore`、`docs/**`、`**/*.md`）、PR main、tag `v*.*.*`。
- 提交信息用中文，格式 `feat:` / `fix:` / `chore:` / `ci:` / `docs:`，与仓库现有历史一致。
- **所有含中文的 `.ps1` 必须以 UTF-8 BOM 保存。** Windows PowerShell 5.1 对无 BOM 的脚本按 ANSI 解码，中文字符会被解释成乱码并破坏解析（实测：`New-Object System.Drawing.Bitmap -ArgumentList $side, $side` 会因参数被吞而报 `参数无效`）。新建或编辑后校验：

  ```powershell
  $b = [System.IO.File]::ReadAllBytes("文件路径")[0..2]
  "{0:X2} {1:X2} {2:X2}" -f $b[0],$b[1],$b[2]   # 必须是 EF BB BF
  ```

### Task 3: Windows 图标

**Files:**
- Create: `files/release/icon.ps1`

**Interfaces:**
- Consumes: `assets/icon.png`
- Produces: `assets/icon.ico`，含 16/32/48/64/128/256 六个尺寸，供 `rsrc` 与 WiX 使用

- [ ] **Step 1: 写图标生成脚本**

`files/release/icon.ps1`：

```powershell
# 由 assets/icon.png 生成多尺寸 assets/icon.ico。
# 用法：powershell -File files/release/icon.ps1
$ErrorActionPreference = "Stop"
Add-Type -AssemblyName System.Drawing

$root = Split-Path (Split-Path $PSScriptRoot -Parent) -Parent
$src = Join-Path $root "assets\icon.png"
$dst = Join-Path $root "assets\icon.ico"
if (-not (Test-Path -LiteralPath $src)) { throw "missing $src" }

# 源图非正方形（319x320），先填充成正方形再缩放，避免变形。
$source = [System.Drawing.Image]::FromFile($src)
try {
    $side = [Math]::Max($source.Width, $source.Height)
    $square = New-Object System.Drawing.Bitmap($side, $side)
    try {
        $g = [System.Drawing.Graphics]::FromImage($square)
        try {
            $g.Clear([System.Drawing.Color]::Transparent)
            $g.InterpolationMode = [System.Drawing.Drawing2D.InterpolationMode]::HighQualityBicubic
            $g.DrawImage($source, [int](($side - $source.Width) / 2), [int](($side - $source.Height) / 2), $source.Width, $source.Height)
        } finally { $g.Dispose() }

        $sizes = 16, 32, 48, 64, 128, 256
        $pngs = @()
        foreach ($s in $sizes) {
            $bmp = New-Object System.Drawing.Bitmap($s, $s)
            try {
                $g2 = [System.Drawing.Graphics]::FromImage($bmp)
                try {
                    $g2.InterpolationMode = [System.Drawing.Drawing2D.InterpolationMode]::HighQualityBicubic
                    $g2.DrawImage($square, 0, 0, $s, $s)
                } finally { $g2.Dispose() }
                $ms = New-Object System.IO.MemoryStream
                $bmp.Save($ms, [System.Drawing.Imaging.ImageFormat]::Png)
                $pngs += , @{ Size = $s; Bytes = $ms.ToArray() }
                $ms.Dispose()
            } finally { $bmp.Dispose() }
        }

        # ICO 容器：6 字节头 + 每图 16 字节目录项 + PNG 数据
        $out = New-Object System.IO.MemoryStream
        $bw = New-Object System.IO.BinaryWriter($out)
        try {
            $bw.Write([UInt16]0); $bw.Write([UInt16]1); $bw.Write([UInt16]$pngs.Count)
            $offset = 6 + 16 * $pngs.Count
            foreach ($p in $pngs) {
                $dim = if ($p.Size -ge 256) { 0 } else { $p.Size }
                $bw.Write([Byte]$dim); $bw.Write([Byte]$dim)
                $bw.Write([Byte]0); $bw.Write([Byte]0)
                $bw.Write([UInt16]1); $bw.Write([UInt16]32)
                $bw.Write([UInt32]$p.Bytes.Length); $bw.Write([UInt32]$offset)
                $offset += $p.Bytes.Length
            }
            foreach ($p in $pngs) { $bw.Write($p.Bytes) }
        } finally { $bw.Flush() }
        [System.IO.File]::WriteAllBytes($dst, $out.ToArray())
        $out.Dispose()
    } finally { $square.Dispose() }
} finally { $source.Dispose() }

Write-Output "wrote $dst"
```

- Produces: `dist/gzgspg-windows-<arch>-<ver>-system.msi`、`...-user.msi`

- [ ] **Step 1: 写 WiX 模板**

`files/release/Product.wxs`。`Scope` 与安装根目录由脚本替换：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Wix xmlns="http://wixtoolset.org/schemas/v4/wxs">
  <Package
      Name="广工商校园网登录器"
      Manufacturer="SummonHIM"
      Version="@@VERSION@@"
      UpgradeCode="8B1F0F13-6E2B-4C3A-9A64-6E0E9F5C2A71"
      Scope="@@SCOPE@@"
      Language="2052"
      InstallerVersion="500"
      Compressed="yes">

    <MajorUpgrade DowngradeErrorMessage="已安装更新版本，无法降级安装。" />
    <MediaTemplate EmbedCab="yes" />

    <!-- 打包时由脚本替换 Name，Scope 决定根目录：系统级用 ProgramFiles64Folder，用户级用 LocalAppDataFolder -->
    <StandardDirectory Id="@@INSTALL_ROOT_ID@@">
      <Directory Id="INSTALLFOLDER" Name="gzgspg">
        <Component Id="MainExecutable" Guid="*">
          <File Id="gzgspg.exe"
                Source="@@EXE@@"
                KeyPath="yes">
            <Shortcut Id="StartMenuShortcut"
                      Directory="ProgramMenuDir"
                      Name="广工商校园网登录器"
                      WorkingDirectory="INSTALLFOLDER"
                      Advertise="yes" />
            <Shortcut Id="DesktopShortcut"
                      Directory="DesktopFolder"
                      Name="广工商校园网登录器"
                      WorkingDirectory="INSTALLFOLDER"
                      Advertise="yes" />
          </File>
        </Component>
      </Directory>
    </StandardDirectory>

    <StandardDirectory Id="ProgramMenuFolder">
      <Directory Id="ProgramMenuDir" Name="广工商校园网登录器" />
    </StandardDirectory>

  </Package>
</Wix>
```

注：`<File Source>` 必须是**绝对路径**。`wix build` 把 `Source` 相对于 **.wxs 文件所在目录**解析，而脚本把模板写到 `%TEMP%`，相对路径必然错。故脚本里用 `Resolve-Path` 把 exe 路径展开为绝对路径后再替换 `@@EXE@@`。`<Package Scope>` 是 WiX v4 的枚举属性（`perMachine` / `perUser`），由它替代手写 `ALLUSERS` / `MSIINSTALLPERUSER` 属性——这是 WiX v4 的推荐写法，也避免了单包内动态改 scope 的升级/卸载问题。

- [ ] **Step 2: 写生成脚本**

`files/release/build-msi.ps1`：

```powershell
# 由 Product.wxs 生成 system / user 两个 MSI。
# 用法：powershell -File files/release/build-msi.ps1 -Version 1.3.0 -Arch amd64 -ExeName gzgspg-windows-amd64.exe
param(
    [Parameter(Mandatory = $true)][string]$Version,
    [Parameter(Mandatory = $true)][string]$Arch,
    [Parameter(Mandatory = $true)][string]$ExeName,
    [string]$DistDir = "dist",
    [string]$OutDir = "dist"
)

$ErrorActionPreference = "Stop"

# MSI 版本必须是四段数字：1.3.0 -> 1.3.0.0
$parts = $Version.Split("-")[0].Split(".")
while ($parts.Count -lt 4) { $parts += "0" }
$msiVersion = ($parts[0..3] -join ".")

# Go 的 GOARCH -> wix 的 -arch 与安装根目录。
# 系统级装在 ProgramFiles64Folder 时必须是 64 位 MSI；386 用 32 位 ProgramFiles。
switch ($Arch) {
    "amd64" { $wixArch = "x64";   $pfDir = "ProgramFiles64Folder" }
    "arm64" { $wixArch = "arm64"; $pfDir = "ProgramFiles64Folder" }
    "386"   { $wixArch = "x86";   $pfDir = "ProgramFilesFolder" }
    default { throw "unsupported arch: $Arch" }
}

$template = Get-Content -LiteralPath (Join-Path $PSScriptRoot "Product.wxs") -Raw

# wix build 把 <File Source> 相对 .wxs 所在目录解析，而模板写到 %TEMP%，故必须用绝对路径。
$exePath = (Resolve-Path (Join-Path $DistDir $ExeName)).Path

$scopes = @(
    @{ Name = "system"; Scope = "perMachine"; RootId = $pfDir },
    @{ Name = "user";   Scope = "perUser";    RootId = "LocalAppDataFolder" }
)

foreach ($s in $scopes) {
    $wxs = $template
    $wxs = $wxs.Replace("@@VERSION@@", $msiVersion)
    $wxs = $wxs.Replace("@@SCOPE@@", $s.Scope)
    $wxs = $wxs.Replace("@@INSTALL_ROOT_ID@@", $s.RootId)
    $wxs = $wxs.Replace("@@EXE@@", $exePath.Replace("\", "\\"))

    $tmpWxs = Join-Path $env:TEMP "gzgspg-$($s.Name).wxs"
    Set-Content -LiteralPath $tmpWxs -Value $wxs -Encoding UTF8

    $out = Join-Path $OutDir "gzgspg-windows-$Arch-$Version-$($s.Name).msi"
    wix build -arch $wixArch -o $out $tmpWxs
    if (-not $?) { throw "wix build failed for scope $($s.Name)" }

    Remove-Item -LiteralPath $tmpWxs -Force
    Write-Output "wrote $out"
}
```

- [ ] **Step 2: 加 build job 的公共准备与 linux 矩阵**

在文件末尾追加（`build` job）：

```yaml
  build:
    needs: [check]
    runs-on: ${{ matrix.jobs.runs-on || 'ubuntu-latest' }}
    strategy:
      fail-fast: false
      matrix:
        jobs:
          - { goos: linux, goarch: "386",   output: "386",   cgo_cc: "gcc -m32", deps: multilib, deb: i386,  rpm: i386 }
          - { goos: linux, goarch: amd64,   output: amd64,   deb: amd64,  rpm: x86_64 }
          - { goos: linux, goarch: arm64,   output: arm64,   cgo_cc: aarch64-linux-gnu-gcc, deps: arm64, deb: arm64, rpm: aarch64 }
    steps:
      - name: Checkout repositories
        uses: actions/checkout@v4

      - name: Set up Go
        uses: actions/setup-go@v5
        with:
          go-version: "1.27"

      - name: Install linux dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y gcc libgl1-mesa-dev xorg-dev libgtk-3-dev libayatana-appindicator3-dev
          if [ "${{ matrix.jobs.deps }}" = "multilib" ]; then
            sudo apt-get install -y gcc-multilib
          fi
          if [ "${{ matrix.jobs.deps }}" = "arm64" ]; then
            sudo apt-get install -y gcc-aarch64-linux-gnu
          fi

      - name: Set up environment variables
        shell: bash
        run: |
          if [[ "${GITHUB_REF}" == refs/tags/* ]]; then
            VERSION="${GITHUB_REF_NAME#v}"
          else
            VERSION="0.0.0-${GITHUB_RUN_NUMBER}"
          fi
          echo "VERSION=${VERSION}" >> $GITHUB_ENV
          echo "PKGVER=${VERSION}" >> $GITHUB_ENV
          echo "PKGARCH_DEB=${{ matrix.jobs.deb }}" >> $GITHUB_ENV
          echo "PKGARCH_RPM=${{ matrix.jobs.rpm }}" >> $GITHUB_ENV
          echo "BUILDTIME=$(date -u +%Y-%m-%dT%H:%M:%SZ)" >> $GITHUB_ENV

      - name: Build binary
        shell: bash
        env:
          GOOS: ${{ matrix.jobs.goos }}
          GOARCH: ${{ matrix.jobs.goarch }}
          CGO_ENABLED: "1"
          CC: ${{ matrix.jobs.cgo_cc }}
        run: |
          set -xeuo pipefail
          mkdir -p dist
          go build -v -trimpath \
            -ldflags "-X 'github.com/summonhim/gzgspg/internal/version.Value=${VERSION}' -X 'github.com/summonhim/gzgspg/internal/version.BuildTime=${BUILDTIME}' -w -s" \
            -o gzgspg
          tar -czf "dist/gzgspg-linux-${{ matrix.jobs.output }}-${VERSION}.tar.gz" gzgspg

      - name: Package DEB and RPM
        shell: bash
        run: |
          set -xeuo pipefail
          go install github.com/goreleaser/nfpm/v2/cmd/nfpm@latest
          "$(go env GOPATH)/bin/nfpm" package -f files/release/nfpm.yaml -p deb -t dist/
          "$(go env GOPATH)/bin/nfpm" package -f files/release/nfpm.yaml -p rpm -t dist/

      - name: Archive production artifacts
        uses: actions/upload-artifact@v4
        with:
          name: linux-${{ matrix.jobs.output }}
          path: dist/*
```

注：`CC: "gcc -m32"` 带空格，Go 会把整个字符串当命令名而失败；实现时改为在 `Build binary` 步骤内按架构设 `export CC="gcc -m32"`，或在矩阵里把 386 的 `cgo_cc` 写成 `gcc` 并额外 `export CGO_CFLAGS="-m32" CGO_LDFLAGS="-m32"`。**留给实现时实测确认**。
